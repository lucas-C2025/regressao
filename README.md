### Regressão

### Passos para sucesso na implementação


**É preciso criar um ambiente virtual para instalação dos módulos**
```
https://github.com/lucas-C2025/regressao.git && cd regressao
python3 -m venv regressao-env
source regressao-env/bin/activate
```
**Após isso será possível usar o comando pip normalmente**
```
pip install pandas matplotlib scikit-learn numpy
```
**Após isso basta executar o código plotando o gráfico**
